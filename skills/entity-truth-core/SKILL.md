# Entity Truth Core

Use this skill to prepare a basic, machine-readable entity profile with deterministic local functions. The tool is not a research engine, crawler, fact checker, trademark search, ranking system, or AI-visibility measurement service.

## Before using the tool

1. Confirm the entity name and use only details supplied by the user or explicitly authorized source material.
2. Do not infer worldwide coverage, served markets, entity languages, official profiles, awards, certifications, dates, metrics, or legal status.
3. Keep user-provided claims labelled as user-provided and unverified.
4. Prefer the MCP tools when the Entity Truth Core MCP server is configured.
5. If MCP is unavailable, use the local CLI only when the package is installed in the user's environment.

## Available MCP tools

- `entity_scan`: run the complete local audit, including the first-100-word candidate scan, limited name hint, and generated draft profile.
- `entity_name_hint`: run the small static word-list heuristic for Arabic, Sorani Kurdish, or English.
- `entity_profile_generate`: generate draft Organization JSON-LD and llms.txt-style text from supplied fields.
- `entity_profile_validate`: perform a limited structural check of an Organization JSON-LD object.

Pass `lang` as `ar`, `ku`, or `en`. Pass `markets`, `knowsLanguages`, `aliases`, `officialProfiles`, and `facts` only when the user has supplied them. Do not add empty or invented values.

## Interpreting results

- Candidate patterns are not verified facts.
- A name hint is based on a small static lexicon; it does not establish global uniqueness or prove a collision.
- Structural JSON-LD validation checks only a limited subset generated by this tool. It is not full Schema.org validation.
- Valid URL syntax does not establish link ownership or official status.
- Generated JSON-LD and llms.txt-style text are drafts and must be reviewed before publication.
- Never describe the score as a search ranking factor, GEO score, AI citation score, or model visibility score.

## Local CLI fallback

From a local checkout, build the project and run:

```bash
npm install
npm run build
node dist/cli.js "Example Organization" --text "User-supplied opening text" --lang en --out-dir ./entity-profile
```

The CLI writes local files only. It refuses to overwrite existing output unless the user explicitly supplies `--force`.

## Privacy and boundaries

The MCP server uses local standard input/output (stdio). It does not start an HTTP listener, call a hosted MAAROOF AI service, access credentials, fetch websites, or transmit entity data. Do not expose user data to another service as part of this skill.

This utility prepares. It does not investigate. Refer users to independent research workflows when they need source verification, global name-collision research, competitor analysis, strategy, or continuous monitoring.
