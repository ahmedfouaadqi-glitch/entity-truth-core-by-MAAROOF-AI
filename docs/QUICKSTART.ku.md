# ڕێنمای خێرای Entity Truth Core

## ئامانج

Entity Truth Core ئامرازێکی سەربەخۆ و ناوخۆییە بۆ ئامادەکردنی پڕۆفایلی ڕێکخراوی کەسایەتی لە زانیارییەکانی بەکارهێنەر. زانیارییەکان ناپشکنێت و لە دەرەوە پشتڕاستیان ناکاتەوە.

## پێداویستییەکان

- Node.js 20 یان نوێتر.
- Git بۆ وەرگرتنی کۆدەکە.
- هیچ API key یان هەژماری خزمەتگوزارییەکی هۆستکراو پێویست نییە.

## دامەزراندن و تاقیکردنەوە

لە فولدەری پڕۆژەکە ئەم فەرمانانە جێبەجێ بکە:

    npm ci
    npm run build
    npm test

## دروستکردنی پڕۆفایل بە CLI

    node dist/cli.js "Example Organization" --text "User-supplied text" --lang ku --window 500 --out-dir ./entity-profile

بۆ هەڵبژاردنی جۆری پڕۆفایل، دەتوانیت `--type Organization` یان `--type LocalBusiness` یان `--type Service` بەکاربهێنیت. جۆری کۆنی `ProfessionalService` هێشتا وەردەگیرێت، بەڵام ئاگادارکردنەوەی کۆنبوونەوەی Schema.org دەردەخات.

بۆ دروستکردنی ڕاپۆرتی Markdown و HTML:

    node dist/cli.js "Example Organization" --report both --out-dir ./entity-profile

ڕاپۆرتەکان ناوخۆیی و بێ پەیوەندیی دەرەکین؛ دەقی کوردیی سۆرانی بە ئاراستەی RTL پیشان دەدەن.

## پرۆسەکردنی CSV

    node dist/cli.js --batch-csv ./entities.csv --out-dir ./batch-output --report both

هەر ڕیزێکی CSV بە سەربەخۆیی پرۆسە دەکرێت. ڕیزێکی هەڵەدار ڕیزە دروستەکان ناوەستێنێت. ئەنجامی هەر ڕیزێک لە `batch-summary.json` تۆمار دەکرێت.

- ناوی ستوونی پێویست: `name`.
- لیستەکان بە نیشانەی `|` لێک جیا دەکرێنەوە.
- خانەکانی `openingHours` و `faqs` دەبێت بە JSON array بن.
- ستوونی نەناسراو یان دووبارەکراو ڕەت دەکرێتەوە.
- فایلی Excel/XLSX بە شێوەی ڕاستەوخۆ پشتگیری ناکرێت.

بۆ وردەکاریی ستوونەکان، `docs/CSV_BATCH.md` بخوێنەوە.

## سنووری تایبەتمەندی و پاراستنی زانیاری

- هیچ وێبسایتێک ناگەڕێت و هیچ داتایەکی دەرەکی ناهێنێت.
- هیچ زانیارییەک بۆ MAAROOF AI یان خزمەتگوزارییەکی هۆستکراو نانێردرێت.
- پاتێرنەکان تەنها نیشانەی ئەگەریین؛ ڕاستی و خاوەندارێتیان پشتڕاست ناکرێتەوە.
- پڕۆفایلە دروستکراوەکان مسودەن و پێویستیان بە پێداچوونەوەی بەکارهێنەر هەیە.
- هەر بەکارهێنەرێک دەتوانێت بە هەژماری خۆی و لە ژێرخانی خۆیدا پەڕەی Playground هۆست بکات.

پێش بەکارهێنانی پڕۆژەکە، `docs/PRODUCT_SCOPE.md` و `SECURITY.md` بخوێنەوە.

ئەم ئامرازە ئامادە دەکات؛ لێکۆڵینەوە و پشتڕاستکردنەوە ناکات.
